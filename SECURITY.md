# Security policy

## Reporting a vulnerability

Report a security problem in this project through GitHub private vulnerability reporting. The report is visible to the maintainer, and it is not a public issue.

1. Open [Report a vulnerability](https://github.com/sixOfOne/dutch-blitz/security/advisories/new) on this repository.
2. If that page has no form, open the **Security and quality** tab, then **Advisories**, then **Report a vulnerability**.
3. Describe what is affected, what someone could do with it, and how to reproduce it if you can.

Please include the details in that report only. A public GitHub issue or a public pull request would publish the problem before there is a fix.

This repository is maintained by one person, so a reply can take several days. Private vulnerability reporting has to be enabled in the repository settings before the form is shown. The owner turns that on by following [docs/repo-security.md](docs/repo-security.md).
